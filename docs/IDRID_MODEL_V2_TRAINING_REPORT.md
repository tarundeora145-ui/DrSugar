## 6. Exact Changes from V1

| Aspect | V1 | V2 |
|---|---|---|
| Imbalance handling | `CrossEntropyLoss(weight=class_weights)` | `WeightedRandomSampler` |
| Loss function | Class-Weighted CE | Plain `CrossEntropyLoss` (no class weights) |
| Max epochs | 15 | 30 |
| LR scheduler | None | `ReduceLROnPlateau` |
| Early stopping | No | Yes (patience=8, metric: Val Macro F1) |

Everything else is identical: MobileNetV3-Small, ImageNet init, 224×224, seed=42, same splits, same augmentations, same normalisation.

---

## 7. Sampling Strategy

**WeightedRandomSampler** was applied to the training `DataLoader` only.

- Sample weights are computed as the inverse of each class frequency in the training split.
- With `replacement=True` and `num_samples=len(training_set)`, every epoch draws a full-sized batch that is balanced across all 5 grades.
- **Validation and test loaders use no sampling** — they iterate over all samples in natural order exactly once.

This approach separates the imbalance correction from the loss signal, unlike V1 where both were applied simultaneously via loss class weights.

---

## 8. Loss Function

`torch.nn.CrossEntropyLoss()` — no class weights. Balance is handled entirely by the sampler.

---

## 9. Augmentation

Identical to V1 (training only):
- `RandomHorizontalFlip()`
- `RandomRotation(10°)`
- `ColorJitter(brightness=0.1, contrast=0.1)`

Evaluation and test transforms: resize to 224×224, normalise only.

---

## 10. Optimizer

`Adam`, lr=1e-4, default PyTorch β₁=0.9, β₂=0.999.

---

## 11. Learning Rate Scheduler

`ReduceLROnPlateau(mode='max', factor=0.5, patience=4)`

- Monitors validation Macro F1.
- Halves the LR if no improvement for 4 consecutive epochs.
- LR was reduced at epoch 20 (from 1e-4 → 5e-5).

---

## 12. Batch Size

16 (identical to V1).

---

## 13. Epochs & Early Stopping

- Maximum: 30 epochs.
- Early stopping patience: 8 epochs (metric: Val Macro F1).
- **Training stopped at epoch 24** — no improvement beyond epoch 16 for 8 consecutive epochs.

## 25. Limitations

1. **Grade 1 extinction persists on test set**: The sampler did improve Grade 1 F1 on the validation set (0% → 28.57%), but test set performance remained 0% (5 Grade 1 test images, all misclassified). The IDRiD Grade 1 sample count (20 training images) is insufficient for reliable test recall.
2. **Test gap vs validation**: V2 validation Macro F1 was 55.19% vs test Macro F1 of 35.97%. This 19pp gap indicates overfitting to the validation distribution — a known issue when training on only 330 images.
3. **Grade 4 regression**: V2 Grade 4 F1 dropped from 38.89% (V1) to 25.00%. This may reflect the sampler increasing Grade 1 exposure at the expense of Grade 4 batch representation.
4. **CPU constraints**: No CUDA acceleration. Longer training budgets and larger architectures remain infeasible without GPU.
5. **No calibration**: Raw softmax probabilities are not calibrated. Confidence values should not be interpreted as true posterior probabilities.
